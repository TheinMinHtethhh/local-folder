ls コマンド

  • ファイルやディレクトリの情報を確認する
  • List の略

ls コマンドの使い方

  1. ls  
  2. ls  パス
  3. ls  オプション  
  4. ls  オプション  パス

ls コマンドのオプション(※1)

  1. ls  -a  (隠しファイルやディレクトリ(※2)を表示)
  2. ls  -l  (ファイルやディレクトリの詳細も表示)
  3. ls  -h  (ファイルサイズを読みやすい単位で表示)
  4. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例：ls  -lah
    (※2) 名前の頭にピリオド(．)が付くファイルやディレクトリ

ls の実行例1

  • 現在のディレクトリ以下のファイルやディレクトリの情報を隠しファイル等含め確認する

ls の実行例2

  • 現在のディレクトリ以下のファイルやディレクトリの詳細を確認する

ls の実行例3

  • 現在のディレクトリ以下のファイルやディレクトリの詳細を表示しつつ，ファイルサイズの単位を読みやすい形で確認する

ls の実行例4-1

  • 現在のディレクトリ以下のファイルやディレクトリの詳細を隠しファイル等も表示しつつ，ファイルサイズの単位を読みやすい形で表示し，lessに引き渡す．

ls の実行例4-2(例4-1の続き)

  • "enter"キーでスクロール，"q"キーで表示終了．

mkdir コマンドの使い方

  1. mkdir  パス
  2. mkdir  オプション
  3. mkdir  オプション  パス

mkdir コマンドのオプション(※1)

  1. mkdir  -v  (ディレクトリ作成毎に結果も表示する)
  2. mkdir  -p  (子ディレクトリ(※2)も一度に作成する)
  3. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例：mkdir  -pv  ./hello/world
    (※2) ディレクトリ以下のディレクトリの意味

mkdir の実行例1

  • 現在のディレクトリにsample04ディレクトリを作成し結果も表示する

mkdir の実行例2

cp コマンド

  • ファイルやディレクトリを複製する
  • Copy の略

cp コマンドの使い方

  • 使い方1：cp  パス  (複製先の)パス
  • 使い方2：cp  オプション
  • 使い方3：cp  オプション  パス  (複製先の)パス

cp コマンドのオプション(※1)

  1. cp  -b  (ファイルの控え(※2)を作成しコピーする)
  2. cp  -i  (警告あり(※3)でファイル・ディレクトリをコピーする)
  3. cp  -f  (警告なし(※4)でファイル・ディレクトリをコピーする)
  4. cp  -r  (ディレクトリを再帰的(※5)に複製する)
  5. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例：cp  -rfb  ./hello  ./hello2
    (※2) コピー先に同名のファイル・ディレクトリが存在した場合，複製を作成しコピーする
    (※3) コピー先に同名のファイル・ディレクトリが存在した場合，警告する
    (※4) コピー先に同名のファイル・ディレクトリが存在した場合，警告しない
    (※5) ディレクトリの中にファイルやディレクトリが存在しても，全てコピーする

cp の実行例1

  • 現在のディレクトリに hello john と記載された john-smith.txt (*1)を作成し内容を確認する． sample04ディレクトリに hello smith と記載された john-smith.txt (*2)を作成し内容を確認する． (*1)を(*2)に控えを作成しつつコピーする．(*2)と控えファイルの内容をそれぞれ確認する．(全て相対パス指定)

cp の実行例2

  • 現在のディレクトリにあるsample04ディレクトリのjohn-smith.txt~ をホームディレクトリにjohn-smith.txtとして警告ありでコピーし内容を確認する．(全て相対パス)

cp の実行例3

  • 現在のディレクトリにあるsample04ディレクトリのjohn-smith.txt をホームディレクトリにjohn-smith.txtとして警告なしでコピーし内容を確認する．(全て相対パス)

cp の実行例4

  • 現在のディレクトリにあるsample04ディレクトリを ファイルも含め警告なしでtest04ディレクトリ以下へコピーしファイルやディレクトリの内容を確認する．(全て相対パス)

rm コマンド

  • ファイルやディレクトリを削除する
  • Remove の略

rm コマンドの使い方

  1. rm  パス
  2. rm  オプション
  3. rm  オプション  パス(複数指定可能)

rm コマンドのオプション(※1)

  1. rm  -i  (削除前に警告する)
  2. rm  -f  (警告なしに削除する)
  3. rm  -r  (ディレクトリ内を再帰的(※2)に削除する)
  4. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例1：rm  -rf  ./hello
    例2：rm  -ri  ./hello
    (※2) ディレクトリの中にファイルやディレクトリが存在しても，全て削除する

rm の実行例1

  • ホームディレクトリの john-smith.txt ファイルを警告ありで削除する．(全て相対パス指定)

rm の実行例2

  • 現在のディレクトリのsample04ディレクトリに移動し， 全てのファイルを警告なしに削除する．(全て相対パス指定)

rm の実行例3

  • ホームディレクトリにあるtest04ディレクトリを，再帰的に警告なしに削除する．(相対パスと絶対パス指定)

mv コマンド

  • ファイルやディレクトリを移動する
  • Move の略

mv コマンドの使い方

  1. mv  パス  (移動先の)パス
  2. mv  オプション
  3. mv  オプション  パス  (移動先の)パス

mv コマンドのオプション(※1)

  1. mv  -b  (ファイルの控え(※2)を作成する)
  2. mv  -i  (警告あり(※3)でファイル・ディレクトリを移動する)
  3. mv  -f  (警告なし(※4)でファイル・ディレクトリを移動する)
  4. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例：mv  -fb  ./hello
    (※2) 移動先に同名のファイル・ディレクトリが存在する場合，バックアップを作成する
    (※3) 移動先に同名のファイル・ディレクトリが存在すれば警告する
    (※4) 移動先に同名のファイル・ディレクトリが存在しても警告しない

mv の実行例1

  • 現在のディレクトリに空のtest01.txtとtest02.txtを作成し test02.txtをtest01.txtに移動し控えを作成する．

mv の実行例2

  • 現在のディレクトリにあるtest01.txt~ファイルを test01.txtに警告ありで移動する．

mv の実行例3

  • 現在のディレクトリのtest01.txtファイルをホームディレクトリにコピーする． ホームディレクトリに移動し，sample04ディレクトリのtest01.txtを現在のディレクトリに警告なしで移動する．(全て相対パス指定)
