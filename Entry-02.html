コマンドの一般的な使い方

コマンド名  処理対象(パスとか)

もしくは

コマンド名  オプション

もしくは

コマンド名  オプション  処理対象(パスとか)

一例

ls  /home/liveuser/

もしくは

ls  -t

もしくは

ls  -la  /home/liveuser

  4. rmdir   (空のディレクトリを削除)
  5. cd   (ディレクトリの移動)

まずはターミナルを開きましょう

pwd コマンド

  • 現在のディレクトリの場所を絶対パス確認する
  • Print working directory の略

pwd コマンドの使い方

  • 使い方1：pwd  
  • 使い方2：pwd  オプション

pwd の実行例

  • 現在のディレクトリの場所を絶対パスで表示する

ls コマンド

  • ファイルやディレクトリの情報を確認する
  • List の略

ls コマンドの使い方

  • 使い方1：ls  
  • 使い方2：ls  パス
  • 使い方3：ls  オプション  
  • 使い方4：ls  オプション  パス

ls の実行例1

  • 現在のディレクトリ以下のファイルやディレクトリの情報を確認する

ls の実行例2

  • 相対パス指定で現在のディレクトリ以下のDesktopディレクトリの情報を確認する

ls の実行例3

  • 絶対パス指定でホームディレクトリの情報を確認する

mkdir コマンド

  • ディレクトリを作成する
  • Make directory の略

mkdir コマンドの使い方

  • 使い方1：mkdir  パス
  • 使い方2：mkdir  オプション
  • 使い方3：mkdir  オプション  パス

mkdir の実行例1

  • 現在のディレクトリにsample01ディレクトリを作成する

mkdir の実行例2

  • 相対パス指定でsample01以下にsample02ディレクトリを作成する

mkdir の実行例3

  • 絶対パス指定でホームディレクトリ以下にsample03ディレクトリを作成する

rmdir コマンド

  • 空のディレクトリを削除する
  • Remove directory の略

rmdir コマンドの使い方

  • 使い方1：rmdir  パス
  • 使い方2：rmdir  オプション
  • 使い方3：rmdir  オプション  パス

rmdir の実行例1

  • 相対パス指定でsample03ディレクトリを削除する

rmdir の実行例2

  • 相対パス指定でsample01以下のsample02ディレクトリを削除する

rmdir の実行例3

  • 絶対パス指定でホームディレクトリ以下のsample01ディレクトリを削除する

cd コマンド

  • ディレクトリを移動する
  • Change directory の略

cd コマンドの使い方

  • 使い方1：cd  
  • 使い方2：cd  パス
  • 使い方3：cd  オプション  パス

cd の実行例1

  • 相対パス指定でDesktopディレクトリに移動する

cd の実行例2

  • 相対パス指定で一階層上のホームディレクトリに移動する

cd の実行例3

  • 絶対パス指定でホームディレクトリ以下のDesktopディレクトリに移動する

cd の実行例4

  • 何も指定しないでホームディレクトリに戻る

touch コマンド

  • 空のファイルを作成する
  • ファイルの更新時間を更新する

touch コマンドの使い方

  • 使い方1：touch  パス
  • 使い方2：touch  オプション  パス

touch の実行例1

  • 現在のディレクトリ以下に空のtest01.txtファイルを作成する

touch の実行例2

  • 相対パス指定で現在のディレクトリ以下のDesktopディレクトリに空のtest02.txtファイルを作成する

touch の実行例3

  • 絶対パス指定でホームディレクトリ以下に空のtest03.txtを作成する

mv コマンド

  • ファイルやディレクトリを移動する
  • Move の略

mv コマンドの使い方

  • 使い方1：mv  パス  (移動先の)パス
  • 使い方2：mv  オプション
  • 使い方3：mv  オプション  パス  (移動先の)パス

mv の実行例1

  • 相対パス指定でDesktopディレクトリにあるtest02.txtファイルを現在のディレクトリに移動する

mv の実行例2

  • 相対パス指定で現在のディレクトリにあるtest01.txtファイルを sample01.txtに移動する(名前の変更と同じ意味)

mv の実行例3

  • 絶対パス指定でホームディレクトリ以下のtest03.txtファイルを ホームディレクトリ以下のDesktopディレクトリに移動する

cp コマンド

  • ファイルやディレクトリを複製する
  • Copy の略

cp コマンドの使い方

  • 使い方1：cp  パス  (複製先の)パス
  • 使い方2：cp  オプション
  • 使い方3：cp  オプション  パス  (複製先の)パス

cp の実行例1

  • 相対パス指定でDesktopディレクトリにある test03.txtファイルを現在のディレクトリに複製する

cp の実行例2

  • 相対パス指定で現在のディレクトリにあるsample01.txtファイル をDesktopディレクトリにsample04.txtとして複製する

cp の実行例3

  • 絶対パス指定でホームディレクトリ以下のtest02.txtファイルを ホームディレクトリ以下のDesktopディレクトリに複製する

rm コマンド

  • ファイルやディレクトリを削除する
  • Remove の略

rm コマンドの使い方

  • 使い方1：rm  パス
  • 使い方2：rm  オプション
  • 使い方3：rm  オプション  パス(複数指定可能)

rm の実行例1

  • 相対パス指定でDesktopディレクトリにある 全てのtxt(*.txt)ファイルを削除する

rm の実行例2

  • 相対パス指定で現在のディレクトリにあるtest02.txtファイル とtest03.txtファイルを削除する

rm の実行例3

  • 絶対パス指定でホームディレクトリ以下のsample01.txtファイルを削除する
