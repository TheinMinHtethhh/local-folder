シェルスクリプト(Shell script)

  • シェルスクリプト(Shell script)とは，シェル(Shell)上で動作する簡便なプログラムのことである． 複数のコマンドを組み合わせて，作業を自動処理させることが可能である．

シェルスクリプトの基本構造

  • シェルスクリプトの基本構造(例)は以下の図のようになる
    #!/bin/sh

    #コメントは頭に    #    をつける(#以降は無視される)
    #行頭の    #!/bin/sh    は使用するシェルを指定する

    echo    "Hello World!!"    #Linuxコマンドを書く(例:echo)
    ls    -la    #Linuxコマンドを書く(例:ls    -la)

シェルスクリプトの実行前準備

  • シェルスクリプトを実行するためには，ファイルに実行権限が必要なので，chmodコマンドで実行権限をつける． 実行権限の付与はファイル作成後に，作成したファイル毎に初回の一回のみおこなえばよい

シェルスクリプトの実行

  • シェルスクリプトを実行するためには，./シェルスクリプト名とする(相対パスでファイル指定)．

実習の準備

  • 実習の前に，ホームディレクトリに演習用ディレクトリ(shells)を作成し移動せよ．

変数に代入できる値の種類(※1, 2, 3)

  1. var="数値"   (変数varに数値を代入．)
  2. var="文字列"   (変数varに文字列を代入．)

変数varにコマンドの実行結果を代入するパターン(例)

  1. var=`コマンド`   (変数varにコマンドの実行結果を代入する．)
  2. var=`コマンド "引数"`   (変数varに引数を与えたコマンドの実行結果を代入する．)
  3. var=`コマンド -オプション`   (変数varにオプション付きコマンドの実行結果を代入．)
  4. var=`コマンド -オプション "引数"`   (変数varに引数を与えたオプション付きコマンドの実行結果を代入．)

変数varにコマンドの実行結果を代入するパターン(例：前ページつづき)

  1. var=`コマンド | コマンド`   (変数varに複数のコマンドで処理した結果を代入．)
  2. var=`コマンド -オプション | コマンド`   (変数varにオプション付き複数のコマンドで処理した実行結果を代入．)
  3. var=`コマンド | コマンド -オプション`   (変数varにオプション付き複数のコマンドで処理した実行結果を代入．)
  4. var=`コマンド -オプション | コマンド -オプション`   (変数varにオプション付き複数のコマンドで処理した実行結果を代入．)
  5. var=`コマンド -オプション "引数"| コマンド -オプション`   (変数varに引数を与えたオプション付き複数のコマンドで処理した実行結果を代入．)
  6. 以降キリがないので省略．組み合わせは無限に存在する．

[ 条件式 ]

  • 条件式を評価する           

[ 条件式 ]

  1. [ 条件式 ]           

基本的な条件式(文字列として比較する場合)

  1. [  $A  =  $B  ]   (変数Aと変数Bの文字列が同じ)
  2. [  $A  !=  $B  ]   (変数Aと変数Bの文字列が異なる)
  3. 他の条件は次回学習する

基本的な条件式(数値として比較する場合)

  1. [  $A  -eq  $B  ]   (変数A  ==  変数B)       
  2. [  $A  -ne  $B  ]   (変数A  !=  変数B)       
  3. [  $A  -gt  $B  ]   (変数A  >  変数B)       
  4. [  $A  -ge  $B  ]   (変数A  >=  変数B)       
  5. [  $A  -lt  $B  ]   (変数A  <  変数B)       
  6. [  $A  -le  $B  ]   (変数A  <=  変数B)       
  7. 他の条件は次回学習する

直前の比較結果が格納される変数

  1. $?   (直前の比較結果(0(真)または1(偽))が格納される)

[ 条件式 ] の実行例1-1

    # 条件比較する
    [    $A    =    $B    ] # 変数Aと変数Bの文字列が同じかどうか?
    echo    $?    # 結果を表示する
