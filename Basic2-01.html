vim コマンド

  • 文章を編集するためにvimエディタを使用する

vim コマンドの使い方

  1. vim  (※1)
  2. vim  テキストファイル名(※2,3)

    (※1)vim単体で起動した場合は，保存時にテキストファイル名を指定する
    (※2)指定したテキストファイルが存在する場合は編集する
    (※3)指定したテキストファイルが存在しない場合は新規作成する

vim コマンドモード時のオプション(文字の挿入(編集モードへ移行))

  1. i  (現在のカーソル位置の前から挿入)
  2. I  (大文字のi. 現在のカーソル位置の行頭から挿入)
  3. a  (現在のカーソル位置の後から挿入)
  4. A  (現在のカーソル位置の行末から挿入)

vim コマンドモード時のオプション(コピー(※1,2))

  1. yy  (現在のカーソル位置から1行コピー)
  2. Nyy  (現在のカーソル位置からN行コピー)
  3. Ny↑  (現在のカーソル位置から上N+1行コピー)
  4. Ny↓  (現在のカーソル位置から下N+1行コピー)
  5. Ny→  (現在のカーソル位置から右N文字コピー)
  6. Ny←  (現在のカーソル位置の1文字前から左N文字コピー)
  7. :Ny  (N行目をコピー)
  8. :N,Ny  (NからN行目までをコピー)
  9. :N,$y  (Nから最終行目までをコピー)

    (※1)各コマンドのNは数字を入力
    (※2)各コマンドでNを省略した場合は，数字は1

vim コマンドモード時のオプション(カット(※1,2))

  1. dd  (現在のカーソル位置から1行カット)
  2. Ndd  (現在のカーソル位置からN行カット)
  3. Nd↑  (現在のカーソル位置から上N+1行カット)
  4. Nd↓  (現在のカーソル位置から下N+1行カット)
  5. Nd→  (現在のカーソル位置から右N文字カット)
  6. Nd←  (現在のカーソル位置の1文字前から左N文字カット)
  7. :Nd  (N行目をカット)
  8. :N,Nd  (NからN行目までをカット)
  9. :N,$d  (Nから最終行目までをカット)

    (※1)各コマンドのNは数字を入力
    (※2)各コマンドでNを省略した場合は，数字は1

vim コマンドモード時のオプション(ペースト，一文字削除，直前の変更内容の取り消し)

  1. p  (直前にカットやコピーした内容のペースト)
  2. x  (現在のカーソル位置の一文字を消す)
  3. u  (直前の変更内容を取り消し．何回でも戻れる)

vim コマンドモード時のオプション(文字列検索(※))

  1. /文字列  (カーソル位置から下方へ文字列を検索)
  2. ?文字列  (カーソル位置から上方へ文字列を検索)
  3. n  (次の候補へ)
  4. N  (前の候補へ)

    (※1)文字列には正規表現も使用可

vim コマンドモード時のオプション(文字列置換(※))

  1. :Ns/文字列1/文字列2/g  (N行目の文字列1を全て文字列2に置き換える)
  2. :N,Ns/文字列1/文字列2/g  (NからN行目の文字列1を全て文字列2に置き換える)
  3. :N,$s/文字列1/文字列2/g  (全文から文字列1を全て文字列2に置き換える)

    (※)各コマンドのNは数字を入力

vim 編集モードからコマンドモードへ切替，コマンドモードの初期化

  1. ESC  (編集モードからコマンドモードへ切替，コマンドモードの初期化(※))

    (※)すでに指定した検索文字列を初期化したい時などに使用する

vim コマンドモード時のオプション(保存，終了処理)

  1. :w  (上書き保存(※1))
  2. :wq  (上書き保存して終了(※2))
  3. :q  (終了(※3))
  4. :q!  (編集内容を破棄して終了)

    (※1,2)新規作成時ファイル名を指定していなかった場合は，ファイル名を指定するように求められる
    (※3)編集内容が変更されていない(もしくは保存されている)場合は終了可能．それ以外はエラー
