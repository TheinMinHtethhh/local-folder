grep コマンド

  • 任意の文字列を検索する

grep コマンドの使い方

  1. grep  検索文字列  パス
  2. grep  オプション  検索文字列  パス
  3. コマンド  |  grep  検索文字列
  4. コマンド  |  grep  オプション  検索文字列

grep コマンドのオプション(※1)

  1. grep  -i  検索文字列  パス(検索文字列に大文字・小文字の区別をなくす)
  2. grep  -v  検索文字列  パス(検索文字列に一致しない行を表示)
  3. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例：grep  -iv  検索文字列  パス

grep の実行例1

  • 現在のディレクトリに sample05 ディレクトリを作成し，このディレクトリに "Hello Ken" と記載された hello-ken.txt を作成する．検索文字列に "Hello" を指定し， 現在のディレクトリ以下のすべてのファイルに対して文字列検索する．(全て相対パス指定)

grep の実行例2

egrep コマンド

  • 任意の文字列を検索する
  • grepの機能拡張版
  • 正規表現を活用できる

egrep コマンドの使い方

  1. egrep  検索文字列(正規表現)  パス
  2. egrep  オプション  検索文字列(正規表現)  パス
  3. コマンド  |  egrep  検索文字列(正規表現)
  4. コマンド  |  egrep  オプション  検索文字列(正規表現)

egrep コマンドのオプション(※1)

  1. egrep  -i  検索文字列  パス(検索文字列に大文字・小文字の区別をなくす)
  2. egrep  -v  検索文字列  パス(検索文字列に一致しない行を表示)
  3. その他のオプション(本日は学習しない)


    (※1) オプションは組み合わせて使うこともできる
    例：grep  -iv  検索文字列  パス

egrep コマンドで使用できる正規表現

  1. ^ (行頭)
  2. $ (行末)
  3. . (任意の1文字を表す)
  4. [] ([]内に指定した文字のいずれかを含む)
  5. [^] ([]内に指定した文字のいずれでもない)
  6. その他の正規表現(本日は学習しない)

egrep コマンドで使用できる正規表現例

  1. ^A (行頭にAを含む)
  2. A$ (行末にAを含む)
  3. .BC (任意の1文字とBC)
  4. [ABC] ([]内に指定したABCのいずれかを含む)
  5. [A-Z] ([]内に指定したAからZのいずれかを含む)
  6. [^ABC] ([]内に指定したABCのいずれでもない)
  7. [^A-Z] ([]内に指定したAからZのいずれでもない)
  8. その他の正規表現(本日は学習しない)

find コマンド

  • ファイルやディレクトリを検索する
  • find "見つける"の意味

find コマンドの使い方

  1. find  パス
  2. find  パス  オプション  条件
  3. find  |  grep  検索文字列
  4. find  |  grep  オプション  検索文字列
  5. find  |  egrep  検索文字列(正規表現)
  6. find  |  egrep  オプション  検索文字列(正規表現)

find コマンドのオプション

  1. find  パス  -name  検索文字列
  2. その他のオプション(本日は学習しない)
